LIC008 Software-KSP Wrapping Harness 0.9.3

این بسته فقط آزمایش توسعه است و محصول یا پذیرش امنیتی نیست.
روی Windows 10 x64 build 14393+ یا Windows 11 x64 build 22000+ غیر Insider، در PowerShell 64-bit و Run as administrator اجرا شود:

powershell.exe -NoProfile -ExecutionPolicy Bypass -File .\Run-Wrapping-Harness.ps1

Namespace این بسته تازه است و به ComparisonV1/ProfileV1 یا کلیدهای محصول دست نمی‌زند.
در شکست، Root و Serviceها را حذف یا دوباره اجرا نکنید؛ خروجی را برای بررسی نگه دارید.
قدیمی یا خارج‌بودن نسخه از پشتیبانی Microsoft مانع این آزمایش نیست. موفقیت فقط feasibility همان میزبان است؛ Reboot/Repair/Windows matrix و ordinary-user هنوز جدا هستند.
